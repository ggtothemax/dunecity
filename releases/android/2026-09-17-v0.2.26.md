# Dune Legacy Android 0.2.26

Android ARM64 release based on the DuneCity 1.0.708 payload.

## Included

- Selectable SimCity and Dune2 graphics skins for DuneCity campaigns and
  per-house custom-game slots.
- Current authored Dune2 zone and special-building Compacts for all available
  houses.
- Matching construction-menu and selected-building portraits.
- Residential growth-stage rendering without native SimCity colour underlays.
- Alpha-aware Scale2x/Scale3x processing for Dune2 skin sprites.

## Package

- Application ID: `net.dunecity.dune2r`
- Version name: `0.2.26`
- Version code: `1000546`
- Asset: `DuneLegacy.apk`

Existing saves and configuration are preserved during upgrade.
