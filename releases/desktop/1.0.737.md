# Dune City 1.0.737

- Campaigns start in public online mode by default, allowing spectators and later join requests. The host can start alone; choose Private for invitation-only play or Offline in the campaign controls. A note explains these choices.
- Adds browser matchmaking: open Play Online and choose Find Match to pair with another waiting player, enter a shared lobby and start a game. Cancel and retry are supported.
- Fixes browser peer cleanup, rejected connections and rematch state. Leaving a game now returns promptly to the menu.
- Corrects direct peer-to-peer command pacing while preserving the existing room relay behavior.
- Includes all of 1.0.735: selectable SimCity/Dune2 graphics, high-detail building art, saved and synchronized skin choices, campaign dropdown fixes, and current hot-join recovery and progress.
- Retains the screenshot guard for physical render-target dimensions, including high-DPI displays.
- Improves Windows dependency caching for subsequent builds.

All multiplayer participants need version 1.0.737. Existing saves, settings and user mods stay in the separate user profile. Browser matchmaking uses the public dunelegacy.com signaling service; direct connectivity still depends on the players' networks, with no default TURN relay.
