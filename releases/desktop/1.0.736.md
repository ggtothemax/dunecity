# DuneCity 1.0.736

- Workshop brings together Map Editor, Mod Editor, Asset Editors, and Community Maps & Mods.
- Edit mod unit/building properties, game rules, AI settings, and metadata in the game.
- Save immutable numbered map/mod revisions with complete asset checksums.
- Browse, share, and download content independently of an online game.
- Multiplayer captures exact content versions; games, saves, and replays retain their original dependencies.
- Replays, How to Play, and About & Credits remain under Extras.

The community API requires the matching PHP service deployment. This source
change includes that service; no public deployment or release is implied by the
local build. Multiplayer protocol10 requires matching game versions.
