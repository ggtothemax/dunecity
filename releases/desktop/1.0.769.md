# Dune City 1.0.769

When the main menu finds a newer signed desktop update, it automatically shows the existing Install update / Later confirmation. The prompt appears once per launch and waits for other menu dialogs to close. Choosing Later keeps it dismissed for that launch; the Update available button can reopen it at any time from the main menu.

Installation still requires explicit confirmation, and matches are never interrupted by an update prompt. Saves, settings and user mods are preserved by the existing updater.

Multiplayer protocol 24 and save format 9846 are unchanged.
